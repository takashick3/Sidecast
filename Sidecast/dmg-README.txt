Sidecast
========

特定アプリの音声だけを HDMI 出力へ流し、それ以外は通常の出力のままにする
macOS 用メニューバー常駐アプリです。

動作環境
--------
- macOS 27 以降
- HDMI などシステムの既定出力とは別の出力デバイス
  （選択したデバイスが既定出力になっている間はタップしません）

インストール
------------
1. Sidecast.app を Applications フォルダにドラッグします
   （ログイン時に起動する機能は /Applications にあるアプリが前提です）
2. Sidecast.app を開きます。メニューバーに波形アイコンが出ます
3. 初回は「システムオーディオ録音」の許可ダイアログが出るので「許可」を選びます

使い方
------
1. メニューバーの波形アイコンをクリックします
2. 「出力先」で HDMI デバイスを選びます
3. 「音を出しているアプリから追加…」で対象アプリを選びます
   （ブラウザは「Safari ▸ GPU」のようにホストアプリ単位で表示されます）
4. 上部のスイッチを ON にすると、対象アプリの音が HDMI から鳴り、
   元の出力先では鳴らなくなります。スライダーで HDMI の音量を調整できます
5. 「ログイン時に起動」をオンにすると、ログイン時に自動で起動します

対象アプリの再起動、HDMI の抜き差し、既定出力の切り替えには自動で追従します。
